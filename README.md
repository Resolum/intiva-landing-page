# Intiva Landing Page

This is the landing page for Intiva, a platform for managing expenses, savings, and incomes.
The landing page provides an overview of the features and benefits of using Intiva, as well as a call to action for users to sign up or learn more about the platform.

## Summary

This static website is a landing page for Intiva, which is a platform for managing expenses, savings, and incomes.
So, it includes the following features:

- Responsive design: The landing page is designed to be responsive and works well on different screen sizes and devices.
- Clear and concise content: The landing page provides clear and concise information about the features and benefits of using Intiva, making it easy for users to understand what the platform offers.
- Call to action: The landing page includes a call to action for users to sign up or learn more about the platform, encouraging them to take the next step in engaging with Intiva.
- Terms of Service and Privacy Policy: The landing page includes links to the Terms of Service and Privacy Policy, ensuring that users have access to important legal information about the platform.
- Benefits section: The landing page includes a section with a list of benefits, such as easy access to financial management tools, and secure data handling, to highlight the advantages of using Intiva.
- About-the-team section: The landing page includes a section with information about the team behind the platform, including their names, and roles, to build trust and credibility with users.

## Technologies Used

For the development of this website, the following technologies were used:

- Astro: A framework for building websites using JavaScript.
- Tailwind CSS: A utility-first CSS framework for rapidly building custom designs.
